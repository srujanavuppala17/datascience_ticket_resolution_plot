# datascience_ticket_resolution_plot

What the Manager Sees in the Box Plot:
The box plot shows resolution times (in hours) for each team:

Key Elements:
Center Line (within the box) = Median Resolution Time

Box Width = Middle 50% of tickets (Interquartile Range, IQR)

Whiskers = Approximate range of typical durations

Dots beyond whiskers = Outliers (tickets that took unusually long)

How to Tell Which Team is Performing Best:
Metric	Meaning for Manager	What to Look For in the Plot / Table
Lower Median	Typical ticket is resolved faster	Box center line is lower on Y-axis
Tight IQR	Team is consistent, low variation	Shorter box (less height)
Lower 95th %ile	Even edge-case tickets are resolved fast	Lower max range in summary table
Few outliers	No chronic delays	Few or no points far above whiskers
